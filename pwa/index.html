📲 Installer sur iPhone (iOS Safari)

Pour utiliser cette application comme une vraie app native sur votre iPhone :

  1. Ouvrez cette page dans Safari sur votre iPhone.
  2. Touchez le bouton Partager (en bas de l'écran).
  3. Faites défiler vers le bas et touchez "Sur l'écran d'accueil".
  4. Validez avec Ajouter en haut à droite.
